
# مدیریت مالی شخصی — نسخه ۱

این پروژه با Python + Kivy ساخته شده و برای اندروید قابل تبدیل به APK است.

امکانات فعلی:
- داشبورد با هزینه امروز و ماه جاری
- ثبت هزینه
- دسته‌بندی هزینه
- ذخیره اطلاعات در SQLite
- گزارش هزینه بر اساس دسته
- تحلیل اولیه و پیشنهاد کاهش هزینه
- رابط کاربری تیره و مدرن

## اجرای روی کامپیوتر
Python را نصب کن و سپس:

pip install -r requirements.txt
python main.py

## تبدیل به APK
برای ساخت APK اندروید، Buildozer روی Linux/WSL استفاده می‌شود.

نمونه:
pip install buildozer
buildozer init

سپس در buildozer.spec:
requirements = python3,kivy

و:
buildozer -v android debug
